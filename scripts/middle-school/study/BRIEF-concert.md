# 내신콘서트 문제 입력 지침 (과 하나의 한 부분)

정수학원 중학교 수업자료 문제 은행에 「내신콘서트」 책의 문제를 **모두** 넣는다(선생님 2026-11-04 「거기에 있는 모든 문제를 다 넣어」). 넣은 문제는 「변형문제」 탭(문제 은행)에만 나온다.
작업 폴더 c:\video-app. 모델 API 호출 금지(그림을 직접 보고 직접 쓴다). 커밋·푸시 금지. src/ 수정 금지. 다른 과·다른 부분 파일은 건드리지 않는다.

## 도구 (Bash, 앞에 `PYTHONIOENCODING=utf-8`)
- 쪽 그림: `python scripts/middle-school/study/concert.py png <학년> <PDF쪽 예: 62 또는 62-63> <출력.png> [dpi=110]` → Read 도구로 본다. 책 쪽 번호 = PDF 쪽 번호(정답·해설 부분은 따로 번호가 붙어 있어 다름).
  - 그림은 **스크래치패드 안에 자기 과·부분 이름의 하위 폴더**를 만들어 넣는다(예: …/scratchpad/concert-중1-5-a/). 글자가 작으면 dpi 140으로 한 쪽씩.
- 넣기: 다 쓴 뒤 `node --env-file=.env.local scripts/middle-school/study/qbank.mjs concert <학년> <과>` 로 검사(미리 보기). 문제 0이 될 때까지 고친다. **`--적용`은 하지 않는다**(두 부분을 합쳐 한 번에 넣는다 — 지시받은 사람이 함).
- 학년: 동아(윤정미) `중1`·`중2`, 동아(이병민) `중1이`·`중2이`. 파일 키는 `중1-5`, `중1이-7`처럼.

## 쓸 파일
`scripts/middle-school/study/data/<키>.concert.<부분>.json` (부분: a = 앞쪽 개념·연습·실전 문제, b = 실전 모의고사). JSON 배열, 책 차례대로:
```
{ "source": "내신콘서트 실전 모의고사 Basic 1회", "no": 3, "area": "어법", "stem": "다음 빈칸에 들어갈 말로 알맞은 것은?",
  "body": ["The movie was ______ than I expected."], "choices": ["good","better","best","well","most good"],
  "answer": "2", "explanation": "than 앞은 비교급 better" }
```
- `choices`가 있으면 객관식(2~5개, ①~⑤ 글자는 빼고 내용만). `answer`는 번호 "2", 복수정답 "1, 4". 서술형은 `choices` 없이 `answer`에 정답 글.
- 여러 문항이 한 지문을 받으면(「[20-22] 다음 글을 읽고…」) 그 문항마다 `"group": { "lead": "[20-22] 다음 글을 읽고, 물음에 답하시오.", "lines": ["지문 문단1", "문단2"] }`를 똑같이 넣고, 문항 자체 글만 body에.
- `area`: 단어(어휘) · 의사소통(대화) · 어법(문법) · 본문(본문·기타 지문·내용 이해). 문항 내용 기준.
- `no`: 책의 문항 번호. 번호가 없는 연습 문제는 빼면 차례대로 붙는다.
- `explanation`: 책 뒤 정답·해설의 해설을 짧게(핵심만). 없으면 "".
- 밑줄은 `<u>…</u>`, 빈칸은 `______`(밑줄 6개 이상), 서술형 답 칸 줄은 `→ ________________________________________`.
- 탭 금지, 쪽 머리·꼬리·저작권·「*빈출유형」「서술형」 같은 꼬리표는 넣지 않는다(「서술형」 표시는 stem 앞에 넣지 않는다).

## 출처 이름(source) — 책 꼭지 그대로, 앞에 「내신콘서트 」
- 앞쪽(a): `내신콘서트 Words 연습 문제 1`, `… Words 연습 문제 2`, `… Words 실전 문제`, `… Dialogues 연습 문제 1`, `… Dialogues 연습 문제 2`, `… Dialogues 실전 문제`, `… Grammar 연습 문제 1`·`2`·`3`, `… Grammar 요점 노트`, `… Grammar 실전 문제`, `… Reading 연습 문제 1`~`4`, `… Reading 실전 문제`, `… Extra Reading 실전 문제` (책에 다른 꼭지가 있으면 그 이름 그대로)
- 뒤쪽(b): `내신콘서트 실전 모의고사 Basic 1회`, `… Basic 2회`, `… Intermediate 1회`, `… Intermediate 2회`, `… 서술형 100%`, `… Advanced`
- 개념 설명 쪽(단어 목록·Words+·문법 설명·본문 구문 분석·Dialogues in Textbook 해설)은 문제가 아니므로 넣지 않는다. 그 쪽 안의 확인 문제는 넣는다.

## 시범 과에서 정한 것(2026-11-04, 중1 5과 394문항)
- 형식 본보기: `scripts/middle-school/study/data/중1-5.concert.a.json`(앞쪽), `중1-5.concert.b.json`(모의고사). 이것과 같은 꼴로 쓴다.
- 책에 위 목록에 없는 꼭지가 있으면 그 이름 그대로(시범 과: `내신콘서트 Dialogues in Textbook`, `내신콘서트 Grammar Quick Test 1`·`2`).
- 한 꼭지 안에서 소단원마다 번호가 1부터 다시 시작해도 책 번호 그대로 쓴다(넣을 때 도구가 다시 매긴다).
- 붙임표(-)는 그대로 쓴다(검사식 고침). 발문의 강조 밑줄(「않은」「없는」「모두」)도 `<u>않은</u>`처럼 표시한다.
- 그림·표 문항은 시범 과처럼 짧은 글로 바꿔 넣는다(숨김 0이 목표).

## 연습 문제(드릴) 쓰는 법 — 책 문항 하나 = 한 문항
- 한 번호 안에 (1)~(10)처럼 작은 문항이 여럿이면 한 문항으로: stem은 책 지시문, body는 「(1) …」 줄들, answer는 「(1) … / (2) … / …」.
- 뜻 쓰기·단어 쓰기 표는 body에 「(1) bakery → ______」 꼴, answer 「(1) 빵집 / (2) …」.
- 대화 순서 배열은 body에 ⓐ… 줄과 마지막 줄 「정답: (____) → (____) → …」, answer 「ⓑ→ⓓ→ⓐ→ⓒ」.
- T/F는 body에 문장들, answer 「(1) T / (2) F …」.

## 그림·표
- 그림을 보고 풀어야 하면 그림 내용을 짧은 글로 body에 넣을 수 있으면 넣는다(「[그림] 남자가 우산을 들고 있다」). 표는 줄글로 푼다(「무게 - Phone A: 150 g, Phone B: 200 g」).
- 글로 바꿀 수 없으면 그래도 입력하고 `"review": "그림 필요"`로 숨긴다. 문제를 지어내거나 바꾸지 않는다.

## 문제·정답·해설 일치 — 꼼꼼히(선생님 2026-11-04 「넣을 때 문제랑 정답이랑 해설이랑 일치하는지 꼼꼼히 확인하도록!!!」)
문항마다 넣기 전에 셋을 맞대 본다.
- **정답 ↔ 문제**: 객관식 정답 번호가 그 보기 내용과 맞는지(보기 차례를 옮기다 밀리지 않았는지), 서술형 정답이 빈칸 수·조건(단어 수, 주어진 단어, 형태 바꾸기)에 맞는지.
- **해설 ↔ 정답**: 해설이 가리키는 번호·낱말이 answer와 같은지(해설은 ③이라는데 answer가 "4"이면 틀린 것). 해설을 다른 문항 것으로 옮기지 않았는지(번호 밀림).
- **문제 ↔ 원본**: 발문·지문·보기 글자가 원본 쪽 그림과 같은지(빠진 줄, 바뀐 낱말, 밑줄 위치).
- 정답 쪽과 문제 쪽의 번호를 하나씩 맞춰 옮기고, 묶음 지문(group) 문항은 지문이 그 번호들에 맞는지 본다.
- 어긋난 것을 찾으면 원본을 다시 보고 고친다. 원본 자체가 어긋나면(책 오류) 고치지 말고 보고서에 적는다.
- 보고서에 「정답·해설 대조: N문항 확인, 고친 것 M(무엇)」을 꼭 적는다.

## 정답 확인 — 하나하나 직접 푼다
- 정답·해설은 책 뒤쪽(대략 PDF 390쪽 이후, 「LESSON 5」 같은 머리로 과가 나뉨)에 있다. 그 과의 정답 쪽을 찾아 옮긴다.
- 옮긴 뒤 **문항마다 직접 풀어** 책 정답과 맞는지 본다. 책 정답이 틀려 보이면 근거를 보고서에 적고 책 정답을 그대로 둔다(원본 그대로).
- 객관식 보기가 정답 둘로 보이면 고치지 말고 보고서에 적는다.
