# 중학교 분석지 작성 지침 (과 하나)

정수학원 중학교 최종통합자료의 분석지. 답은 한국어. 작업 폴더 c:\video-app. 모델 API 호출 금지 — 직접 분석해서 쓴다. 커밋·푸시 금지. src/ 수정 금지.

읽을 것(먼저 꼭): 
- `scripts/middle-school/analysis/build.mts` 머리글(형식), `scripts/tmp-rv/ana-1027b/SPEC.md`(선생님 확정 표기 규칙)
- 동아(이병민)은 학년에 「이」를 붙여 부른다(`dump.mjs 중1이 2`, 키 `중1이-2`). 본보기: `scripts/middle-school/analysis/out/중1-1.json`(이 수준·분량으로)

순서:
1. `node --env-file=.env.local scripts/middle-school/analysis/dump.mjs <학년> <과>` → `analysis/in/<학년>-<과>.json`(문장·과 문법 이름)
2. `analysis/out/<학년>-<과>.json` 손으로 작성. 문장 수·차례를 입력과 똑같이.
3. `npx tsx --env-file=.env.local --tsconfig tsconfig.json scripts/middle-school/analysis/build.mts <학년>-<과>` 로 검증, 버려진 것이 0이 될 때까지 고친다. 0이면 `--저장`.

표기 규칙(선생님 확정, 어기면 안 됨):
- 준동사(to부정사·동명사·분사)에는 V를 달지 않는다. 절 안 동사만 V.
- M은 부사·전치사구만. 형용사구에 M을 달지 않는다.
- 명령문 해석은 「~하라」.
- 해석은 교재 해석(입력의 ko)을 기준으로 삼되, 틀리지 않게. 맞는 해석을 망치지 말 것.
- 중학교 수준: 성분 S·V·O·C·M(·A), 이름표·번호 설명은 그 과 문법과 시험에 나올 자리만. 설명을 지어내지 말고 문장마다 직접 따져 본다.
정한 것: 
- 명령문은 교재가 존댓말이어도 「~하라」, 그 문장 전체를 평어로(「꽂기만 하라, 그러면 … 될 것이다」). 
- 인사말·「Why?」 같은 짧은 문장은 성분 없이 해석만, 직독직해 생략. 
- 동사에 꼭 필요한 부사어는 A, 그 외 부사·전치사구는 M. 
- 이름표는 그 과 문법 이름과 SPEC의 목록 안에서 중학 수준에 맞는 것만. 번호 설명은 같은 문법이 반복되면 첫 자리와 시험 빈출 자리에만 단다. 
- 「Please …」 같은 정중한 부탁과 대화 속 호소는 교재 해석(존댓말)을 그대로 둔다.
- 해석을 바꾼 명령문은 보고할 필요 없다. 정말 판단이 갈리는 문장만 보고한다.
함정: 직독직해 chunks는 2조각 이상이어야 실린다. 축약 'm 은 q:"'m". q는 원문 글자 그대로(같은 글자가 둘이면 occ).

마지막 보고(이것만, 짧게): 과 이름, 저장한 문장 수, 버려진 것 수(0이어야 저장), 판단이 애매해 선생님 확인이 필요한 문장, 못 끝낸 것.
